# Hai — Software Engineer Portfolio

A personal portfolio focused on Software Engineering, E-commerce and Design Systems.

## Stack

- React
- TypeScript
- Vite
- HTML5
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize before publishing

1. Replace the name/email/LinkedIn/GitHub placeholders in `src/main.tsx`.
2. Replace project descriptions with projects you are allowed to disclose.
3. Add real screenshots or links only for public work.
4. Add a PDF CV link if desired.
5. Deploy to Vercel, Netlify or another static hosting service.

## Important

Do not upload proprietary source code, confidential client information, private screenshots or employer-owned assets. Use personal demos for anything that cannot be publicly disclosed.
